## 1. THE DONUT (consumer / publisher surface)

Use for shop.thedonut.co landers, advertorial chrome, sprinkle-forward creatives that run as Donut editorial.

### Logo
- Primary 99% of the time: **black background + white logotype** (horizontal).
- Secondary: white background variants.
- Vertical lockups for constrained space.
- Clear space = height of the letter **D** on all sides.
- **Don't:** modify mark/text, put on color or textured backgrounds, distort.

### Typography
- Font: **Poppins** (Google Fonts). Bold for headlines/labels/buttons; Regular for body.
- Hierarchy: labels/tags → primary headings → secondary headings → subhead → body.

### Color (hex)
| Name | Hex | Role |
|------|-----|------|
| Midnight | `#1A1418` | Primary background (prefer over pure black when following this deck) |
| Periwinkle | `#4C51F0` | Buttons / accents |
| Chocolate | `#6C3C31` | Accents |
| Dark Gray | `#6C6569` | Subtext |
| Pink | `#F84FAA` | Fun accents / gradients |
| Yellow | `#EBBC60` | Accents |
| Mid Gray | `#D1CDD0` | Borders |
| Light Blue | `#31C9FF` | Text links / icons |
| Light Gray | `#F5F4F5` | Light backgrounds |
| Green | `#50E3C2` | Accents / CTA areas |
| Cream | `#FFFCE9` | Alt to white behind secondary logo |

Energy: modern, bold, playful. Sprinkle textures sparingly (dark sprinkles behind dark colors; light behind light). Icons: 48×48 artboard, 2px stroke.

### Voice on Donut surfaces
- Publisher editorial trust, not brand PR.
- Advertorial gold standard: first-person bylined discovery story (see Curativa Bay refs).
- No em dashes (Alyssa hard rule).

## 2. DONUT PRESS MEDIA (B2B / media kit surface)

Use for Press Media decks, sponsor kits, cyan-on-black UI, donutpressmedia.co.

### Logo
- Primary: horizontal on **dark/black**, **cyan** wordmark.
- Square lockup for social avatars / app icons.
- Clear space = height of **D**.
- **Don't:** colorful/busy/textured backgrounds, distort, re-arrange mascot + wordmark.

### Color (hex)
| Name | Hex | Role |
|------|-----|------|
| Black | `#000000` | Primary background |
| Cyan | `#36F5E8` | Wordmark / buttons / CTA |
| White | `#FFFFFF` | Body on dark |
| Off White | `#F5F4F5` | Light bg / secondary |
| Mid Gray | `#6C6569` | Subtext |
| Light Gray | `#D1CDD0` | Borders |
| Extra Accent | `#FECC9A` | Icons / extra buttons |
| Yeti Dark Accent | `#99325B` | Icons |

### Typography
- Primary: Arial / Helvetica Neue (guide also lists Inter / Barlow Condensed as alternatives).
- Headlines **all caps · bold**; body regular; buttons cyan fill · black text · bold · all caps.
