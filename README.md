# trl-grok-bots

Source of truth for TRL Launchpad Grok Bot personas.

Each bot is a markdown file with four fields: one job, anti-jobs, voice, wake. Files map 1:1 to CreateAgent / UpdateAgent.

## Active roster

- **Chief of Staff** — fleet oversight for Alyssa
- **Scout**, **Contact Finder**, **Deal Desk**, **Contracts** — partnerships
- **Brief Studio**, **Production Desk**, **Creative Tracker** — creative / production

## Explicitly not building

Librarian, Quality Desk, old Traffic, Influencer Manager, Creative Producer (middle managers) — dropped in favor of the roster above.
